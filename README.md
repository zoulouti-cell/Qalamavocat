# قلم — منصة تسيير مكاتب المحاماة بالمغرب

تطبيق ويب لمكاتب المحاماة (React + TypeScript + خدمة Node)، بواجهة عربية/فرنسية/إنجليزية
(عربي RTL، والفرنسية والإنجليزية LTR) وهوية خضراء–ذهبية. يعمل محليًا عبر `Qalam.exe`
كنافذة تطبيق، وقابل للنشر على نطاق خاص عبر HTTPS.

> **الحالة:** المراحل الثماني منجزة — 19 شاشة، خدمة API متعددة المكاتب مع عزل كامل،
> مصادقة وصلاحيات، وثائق ومحرر A4، مكتبة قانونية، مساعد بضوابط عدم الاختلاق،
> إدارة منصة، ونشر محمي.
> **114 فحصًا آليًا ناجحًا (6/6 مجموعات)** — التفاصيل في [docs/TEST-REPORT.md](docs/TEST-REPORT.md).

## التشغيل السريع

```bash
pnpm install
pnpm build            # بناء الواجهة
pnpm web              # http://127.0.0.1:4310
```

أو استخدم `dist-app/Qalam-Web/Qalam.exe` (ينشئ قاعدة البيانات بجانبه ويفتح النافذة).

### تكامل بوابة محاكم.ما

بوابة `mahakim.ma` محمية بجدار حماية يرفض الطلبات الآلية كما تحقّقنا منه (`Requête rejetée`)،
لذلك لا يتم كشط الموقع. البديل المطبَّق في «الملفات ← سحب من محاكم.ما»:

1. إدخال المحكمة ورقم الملف والسنة → **فتح البوابة** في المتصفح عبر `shell.openExternal`.
2. لصق نتيجة البحث كما تظهر → **تحليل النص** (`src/lib/mahakim.ts`).
3. استخراج: رقم الملف (يدعم الأرقام العربية ٠-٩)، المحكمة، الموضوع، وتواريخ الجلسات.
4. **إنشاء ملف** في المكتب مباشرة بالبيانات المستخرجة.

المحلّل مُختبَر على نص نموذجي: `1201/45/2026` · `المحكمة الابتدائية بالرباط` ·
`النفقة والحضانة` · جلستان `21/10/2026` و`18/11/2026`.

### المساعد القانوني — قواعد صارمة

- **لا يخترع مراجع** ولا مواد قانونية ولا أحكامًا: كل ادّعاء قانوني يُسند إلى مادة في مكتبة المكتب،
  وإن لم يوجد مصدر يصرّح صراحةً «لا مصدر موثوق» ويقترح إضافة النص.
- **تمييز نوع المعلومة** في كل إجابة: `نص قانوني` · `اجتهاد قضائي` · `تحليل` · `معطيات المستند` · `لا مصدر`.
- **تنبيه التحقق** عند الاستناد إلى نص قانوني: راجع آخر صيغة منشورة في الجريدة الرسمية.
- **السياق**: ملف / مادة من المكتبة / نص ملصق — ولا يستخدم بيانات أي مكتب آخر.
- **الخصوصية**: الإرسال الخارجي معطّل افتراضيًا، ولا تُرسل مستندات لأي خدمة دون إعداد وصلاحية.
- **بحث خارجي اختياري** (مفتاح «بحث خارجي»): عند تعطيله لا يخرج أي شيء من الجهاز؛ وعند تفعيله
  يُرسل **السؤال فقط** إلى خدمة البحث عبر الـAPI، وتُعرض النتائج بوسم «مصدر خارجي» مع **تنبيه تحقق**
  من المصدر الرسمي. لا تُحفظ النتائج كسند قانوني ولا تُخلط بالنصوص الموثقة.
- إجراءات: تلخيص · مسودة مذكرة (قالب) · استخراج الوقائع/التواريخ/المبالغ/الطلبات · مهام تحتاج تحققًا
  (بدون إدراج مدد قانونية من عندنا) · بحث في المكتبة.

### قوالب التحرير من نماذج المكتب

ملفات PDF التسعة (مقال افتتاحي، مذكرة جوابية، عقد، إنذار، مذكرة تعقيبية، مقال استئنافي،
مذكرة بأسباب النقض، شكاية مباشرة، مقال استعجالي) كانت **صورًا ممسوحة بلا طبقة نص**،
فاستُخرجت عبر: `pdfjs` → `@napi-rs/canvas` (تصيير الصفحة) → `tesseract.js` (ara) → تنقية الأسطر.

- النصوص في `src/data/templates.ts` وتُحمَّل تلقائيًا في المحرر عند اختيار القالب.
- صُحّحت أخطاء OCR الشائعة: «السيدلة)»→«السيد(ة)»، «المستأئف»→«المستأنف»،
  «استثنافي»→«استئنافي»، «تحميا»→«تحميل»، وحُذفت أسطر الضجيج.
- **ملاحظة:** هذه نصوص مستخرجة آليًا وتحتاج مراجعة المحامي قبل استعمالها في ملف حقيقي.

- صفحة طباعة نظيفة `#/print/letterhead` (وللمذكرات `#/print/memo`) بحجم **A4** وهوامش
  تُقرأ من إعدادات الرأسية، بلا أي واجهة تطبيق.
- `pnpm pdf` يولّد ملفًا فعليًا عبر Chrome headless ويتحقق منه:
  ```
  pdf: docs/preview/letterhead.pdf
  valid: true · pages: 1 · size: 65.2 KB
  ```
- الزر «تصدير PDF» داخل التطبيق يفتح صفحة الطباعة حيث يمكن الطباعة أو الحفظ PDF مباشرة.

### القارئ الضوئي (OCR)

- مرتبط بخمسة أقسام: **المكتبة** (مادة كاملة + اقتراح فرع) · **الموكلون** (الاسم/الهاتف/البطاقة/البريد/العنوان)
  · **الملفات** (رقم الملف/المحكمة/الموضوع) · **المذكرات** (إدراج نص ممسوح في المسودة)
  · **الرأسيات** (اسم المكتب/الصفة/العنوان/الهاتف/البريد).
- زر **«القارئ الضوئي»** في كل قسم: ارفع صورة أو PDF → يُستخرج النص → تُعرض الحقول المستخرجة
  للمراجعة → «استعمال البيانات» يملأ النموذج تلقائيًا.
- **تحسين الدقة**: تصغير الصور الكبيرة إلى 2200px، تدرّج رمادي بتباين خفيف،
  `preserve_interword_spaces`، ونموذجا **ara+fra**.
- الصور: `tesseract.js` · PDF: `pdfjs-dist` (طبقة النص حتى 12 صفحة).
- **Word (.docx):** يُقرأ مباشرة دون OCR — فك الأرشيف بـ`fflate` ثم استخراج `word/document.xml`
  وتحويله نصًا (فقرات، أسطر، رموز). الصيغة القديمة `.doc` تُرفض برسالة واضحة.
- **تحقّق**: مستند عربي مولّد بـ`python-docx` استُخرج كاملًا → **5 passed**
  (العنوان، الجملة الأولى، الأسطر المتعددة، تحويل XML).
- **تحقّق فعلي**: صورة عربية مولّدة بـ Chrome استُخرجت بدقة **89%** ونص مطابق حرفيًا.

### الدخول (بريد · هاتف · Google)

- **بالبريد:** تسجيل/دخول عبر `/api/auth/register|login` مع رسائل خطأ دقيقة.
- **بالهاتف:** تبويب مستقل — إرسال رمز (`/api/auth/otp/request`) ثم التحقق (`/api/auth/otp/verify`).
  في التطوير يُعرض الرمز على الشاشة (`devCode`) إلى حين ربط مزوّد SMS.
- **بحساب Google:** OAuth 2.0 **Authorization Code + PKCE** في Electron:
  `createPkce` / `buildAuthUrl` / `exchangeCode`، وخادم استماع محلي على `127.0.0.1` يعيد `code`،
  والتحقق من `state`، ثم `/api/auth/google` لإنشاء الجلسة. يُفعَّل بإدخال **Client ID** في الإعدادات.
- **اختبارات:** `node apps/desktop/electron/google-oauth.test.cjs` → **5 passed**
  (PKCE = SHA256، معاملات الرابط، فك ID token، مقاومة التالف).

### خدمة API (multi-tenant)

خدمة حقيقية بلا تبعيات خارجية: تسجيل/دخول بالبريد، OTP بالهاتف، دعوات، رمز إنشاء متغيّر كل 4 ساعات،
إدارة منصة، و**عزل صارم** لكل جدول بـ `office_id`.

**مربوطة بالتطبيق:** شاشة الدخول تستدعي `signIn/signUp`، والجلسة تُحفظ وتُعرض في الشريط الجانبي
(اسم المكتب + المستخدم + شارة «محلي»)، وفي الإعدادات بطاقة «الاتصال بالخادم» لاختبار العنوان.
وضع «متابعة محليًا» يبقى متاحًا للعمل دون خادم.

**مزامنة المجموعات:** `src/data/remote.ts` يوفّر `useSyncedCollection` — محلي أولًا ثم الخادم:
عند وجود جلسة سيرفر تُجلب الموكلون والملفات وتُستبدل النسخة المحلية، وكل إضافة تُدفع إلى الخادم
(`push`) والحذف يُبلَّغ (`removeRemote`). المكتبة لها محوّل جاهز (`libraryAdapter`) بانتظار ربط الصفحة.

```bash
pnpm api        # http://127.0.0.1:4310
pnpm api:test   # 19 passed, 0 failed
```

التفاصيل والمسارات: [docs/api.md](docs/api.md).

### مزامنة Google Drive (ثنائية الاتجاه)

`services/sync/drive.mjs` — محرّك مستقل عن مصدر التخزين:

- `createLocalAdapter(dir, fs)` — مجلد المكتب.
- `createGoogleDrive({ accessToken, folderId })` — Drive REST v3 (list/search/upload/download, multipart).
- `createMemoryDrive()` — بديل للاختبار.
- `syncTwoWay({ local, remote })` — يرفع الجديد/الأحدث محليًا، ينزّل الجديد/الأحدث من Drive،
  يتخطى المتطابق، ويعيد تقريرًا `{uploaded, downloaded, skipped, errors}` دون التوقف عند خطأ ملف واحد.

في الإعدادات: زر «ربط Google Drive» يفتح حقول **رمز الوصول** و**معرّف المجلد** ثم **«مزامنة Drive»**
عبر IPC `qalam:drive-sync`، ويعرض ↑/↓/⊘. (يتطلب OAuth Client ID من Google Cloud — لم يُنشأ هنا لغياب بيانات الاعتماد.)

**اختبارات:** `pnpm sync:test` → **8 passed** (رفع محلي، تنزيل بعيد، أحدث محليًا، أحدث بعيدًا، لا نقل عند التطابق، خطأ معزول).

- `data/store.ts` يوفّر `useCollection(key, seed)` بمصدر واحد للحقيقة بين الصفحات
  (اشتراك حيّ: إضافة موكل في صفحة تظهر فورًا في قائمة الموكلين داخل نموذج الملف).
- المجموعات الحالية: `qalam.clients` · `qalam.cases` · `qalam.library` ·
  `qalam.schedule` · `qalam.offices` · `qalam.letterhead`.
- التخزين اليوم `localStorage`، والواجهة مصمّمة لتبديله بمحوّل **SQLite** أو مزامنة سحابية
  دون تعديل الصفحات (كل صفحة تتعامل مع `useCollection` فقط).

- **الأرقام:** لاتينية دائمًا (`-u-nu-latn`) كما في الوثائق المغربية.
- **التوجيه:** HashRouter (متوافق مع `file://` داخل Electron).
- **الثيم الداكن:** إعادة تعريف رموز `--color-*` داخل `.dark` + قاعدة `.dark .bg-white` لقلب أسطح
  البطاقات فقط، مع إبقاء `--color-white` سليمًا حتى لا ينقلب `text-white` (عناوين البانر والشريط الجانبي).
  يمكن معاينة أي شاشة بالوضع الداكن عبر `#/route?theme=dark`.


## التوزيع والنشر

### 1) نسخة تشغيل جاهزة (exe)

`dist-app/Qalam-Web-win64.zip` (38MB) — فك الضغط ثم شغّل `Qalam.exe`:

```
Qalam-Web/
  Qalam.exe      ← الملف التنفيذي (يفتح المتصفح تلقائيًا على 127.0.0.1:4310)
  node.exe       ← Node مضمّن (لا حاجة لتثبيت)
  README.txt     ← تعليمات التشغيل والنسخ الاحتياطي
  app/
    web/         ← واجهة التطبيق المبنية (dist)
    services/    ← خدمة الـAPI
    qalam.db     ← تُنشأ عند أول تشغيل
```

- لا يحتاج تثبيتًا ولا اتصال إنترنت، ويعمل من فلاشة.
- **النسخ الاحتياطي:** انسخ `app/qalam.db`.
- **التحديث:** استبدل `app/web` ببناء جديد (`pnpm build`).

**إعادة بناء الحزمة (آلية):**
```powershell
pnpm dist:web              # يبني الواجهة ثم يجهّز الحزمة ويضغطها
pnpm dist:web -- --no-build    # بدون إعادة بناء (يستعمل dist الحالية)
pnpm dist:web -- --rebuild-exe # إعادة تصريف Qalam.exe من packaging/QalamLauncher.cs
pnpm dist:all              # كل شيء: الحزمة + حزمة المصدر + التحقق من الخدمة داخل الحزمة
```

ملفات المصدر للحزمة في `packaging/`: `QalamLauncher.cs` و`qalam.ico`.
